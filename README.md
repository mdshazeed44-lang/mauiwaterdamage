# Maui Water Damage Pros — Website Mockup

A modern, clean, conversion-focused marketing website for **Maui Water Damage Pros**, a 24/7 water damage restoration & mitigation company serving Maui, Hawaii.

## ✨ Highlights
- **6 pages** — Home, Services, Water Damage Restoration, Service Areas, About, Contact
- **Clean, minimal, professional** design (white-first, blue + teal accents)
- **Fully responsive** (desktop → mobile) with a sticky mobile call bar
- **Built for AI & local SEO** — JSON-LD structured data (LocalBusiness, FAQPage, Service), conversational FAQs, and Maui location targeting for Google AI Overviews, ChatGPT, and voice search
- **Interactive & animated** — Lenis smooth scrolling, scroll progress bar, Before/After comparison slider, insurance-partner marquee, water-bubble effects, 3D hover tilts, and scroll-reveal animations

## 🧱 Tech
Plain, dependency-light **HTML + CSS + JavaScript** (no build step). Lenis smooth scroll loads from CDN.

```
├── index.html                      # Home
├── services.html                   # Services overview
├── water-damage-restoration.html   # Cornerstone service page
├── service-areas.html              # Local SEO / service areas
├── about.html                      # About us
├── contact.html                    # Contact + request form
└── assets/
    ├── css/styles.css              # Design system + components
    └── js/main.js                  # Interactions & effects
```

## ▶️ View locally
Just open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
